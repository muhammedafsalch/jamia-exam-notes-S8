# 🏛️ Jamia Nooriyya (JJC) S8 Exam Study Portal & Solved Papers

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Web-green.svg)](https://www.digiexams.in/afsal/)
[![Languages](https://img.shields.io/badge/languages-Arabic%20%7C%20Malayalam%20%7C%20English-orange.svg)](#)

A comprehensive, interactive web portal and study companion designed for students of **Jamia Nooriyya Arabic College & Affiliated Junior Colleges (JJC)** preparing for the **Semester 8 (S8 / Final Year Degree)** examinations.

The portal covers **7 core subjects** and classical Islamic sciences, featuring complete classical texts (*Matn*), commentary (*Sharh*), easy-to-understand Malayalam analytical explanations (*Mas'ala vivaranam*), and fully solved previous year question papers (2023, 2024, and 2025).

## ✨ Key Features

- **🎓 Solved Question Papers (2023, 2024, 2025):**
  Detailed answers, authentic textual citations (*Ibarath*), Malayalam summaries, and exam-oriented marks breakdown for all 7 subjects.
- **📖 Multi-Mode Reading View:**
  - ✨ **Simplified Study Mode:** Shows the core *Matn* paired with intuitive Malayalam *Mas'ala* explanations.
  - 📜 **Matn Only Mode:** Focused classical text reader (Imam Nawawi's Minhaj al-Talibin, etc.).
  - 🌐 **Malayalam Translation Mode:** Clean translated dars notes for quick revision.
  - 🖋️ **Sharh Mode:** Classical commentary presentation (Imam Jalaluddin al-Mahalli, Imam Taftazani, etc.).
  - 📖 **Tri-View (All):** Complete simultaneous comparative layout.
- **🔍 Quick Search & Filter:** Instant in-browser search across chapters, topics, Arabic keywords, and question numbers.
- **🕌 Quran & Asbab al-Nuzul Integration:** Dedicated Surah-by-Surah study with revelation context and Jalalayn explanations.
- **📱 Responsive & Typography-Optimized:** Tailored typography combining *Amiri*, *Scheherazade New*, and *Noto Sans Malayalam* for maximum readability on mobile, tablet, and desktop.

## 🚀 Getting Started

Since this project is built with standard HTML5, CSS3, and JavaScript, no complex build system or runtime compilation is required.

### 1. Clone the Repository
```bash
git clone https://github.com/muhammedafsalch/jamia-exam-notes-S8.git
cd jamia-exam-notes-S8
```

### 2. Run Locally
You can open any HTML file directly in your browser, or use a local HTTP server:

Using Python:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

Using Node.js (`npx serve`):
```bash
npx serve .
```

Or run via Apache / XAMPP by placing this folder in your web root (`htdocs`).
